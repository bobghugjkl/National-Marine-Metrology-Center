# 表格固定列与水平滚动实现说明

## 需求描述

实现表格的固定列和水平滚动功能，具体要求：

1. 当页面宽度足够时，显示完整表格
2. 当页面宽度不足时，保持"序号"和"操作"列固定在左右两侧，其他内容可以水平滚动
3. 底部有滚动条可以滚动查看其他内容

## 实现方案

### 1. 修改表格容器

在 `table-custom.vue` 组件中添加表格容器，设置水平滚动：

```html
<div class="table-container">
    <el-table class="mgb20" :style="{ width: '100%' }" border :data="tableData" :row-key="rowKey"
        @selection-change="handleSelectionChange" @row-click="handleRowClick" table-layout="auto">
        <!-- 表格内容 -->
    </el-table>
</div>
```

```css
.table-container {
    overflow-x: auto;
    width: 100%;
    margin-bottom: 20px;
}
```

### 2. 添加固定列配置

修改 `el-table-column` 组件，添加固定列配置：

```html
<el-table-column v-if="item.visible" :prop="item.prop" :label="item.label" :width="item.width"
    :type="item.type" :align="item.align || 'center'" :fixed="item.prop === 'operator' ? 'right' : item.fixed">
    <!-- 列内容 -->
</el-table-column>
```

### 3. 配置固定列

在任务管理页面中，配置序号列和操作列为固定列：

```javascript
let columns = ref([
    { type: 'index', label: '序号', width: 80, align: 'center', fixed: 'left' },
    // 其他列...
    { prop: 'operator', label: '操作', width: 220, fixed: 'right' },
])
```

## 技术实现

### Element Plus 表格固定列

使用 Element Plus 的 `fixed` 属性实现列固定：

- `fixed="left"`: 固定在左侧
- `fixed="right"`: 固定在右侧

### CSS 实现水平滚动

使用 CSS 的 `overflow-x: auto` 实现水平滚动：

```css
.table-container {
    overflow-x: auto;
    width: 100%;
}
```

## 效果说明

### 宽屏显示
- 表格完整显示
- 无水平滚动条
- 所有列正常展示

### 窄屏显示
- "序号"列固定在左侧
- "操作"列固定在右侧
- 中间内容可以水平滚动
- 底部显示水平滚动条

## 注意事项

1. **固定列宽度**：固定列必须设置明确的宽度（`width`）
2. **非固定列**：建议使用 `minWidth` 而不是 `width`，以便更好地适应不同宽度
3. **性能考虑**：固定列会增加渲染复杂度，不建议固定过多列
4. **兼容性**：此方案在所有现代浏览器中都能正常工作

## 后续优化建议

1. **响应式调整**：可以根据屏幕宽度动态调整固定列
2. **列宽调整**：可以添加列宽调整功能
3. **列显示控制**：可以添加列显示/隐藏控制
4. **记住用户设置**：可以将用户的列设置保存到本地存储
